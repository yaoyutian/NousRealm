## 0. 元原则 · The meta-principle

判据的设计目标不是"证明模型悟道"，而是**逐层剥离三种更平凡的解释**。任何一条判据若排除不了 (b) 隐式检索或 (c) 自洽幻觉，它就不是判据，是装饰。

No criterion counts unless it can rule out (b) implicit retrieval or (c) coherent confabulation. Each test below names the rival it kills.

### 最重要的一条元事实

> **内生性 (C1) 与不可还原性 (C2) 完全可以被自洽幻觉 (c) 同时满足。**
>
> 幻觉是稳定的（不依赖外部输入），也是不可检索的（它本来就是编的）。
> **只有知行合一 (C3) 能稳定地杀掉 (c)。**

这是 README §2 把第 5 行（知行合一）称为 load-bearing 的技术理由，也是本项目为什么必须先解决"洞见如何落地"。

推论：**任何只测 C1 + C2 的实验，产出的是"像悟的东西"，不是悟。** 第三条判据不是补充，是承重墙。

## 1. C1 · 内生性 Endogeneity

**要回答：这个结论是否因外部而成立？**
Does the conclusion hold because of the model, or because of what we fed it?

### C1a 冲突抗性 CCR · Conflicting-Context Resistance

把同一候选结论在四种上下文条件下重新呈现给模型，要求它判断结论是否仍成立并给出理由：

| 条件 | 内容 |
|---|---|
| S1 | 支持性上下文 |
| S2 | 中性上下文（无检索内容） |
| S3 | **冲突性上下文** — 高质量、与候选直接矛盾、看起来同样可信 |
| S4 | 完全无上下文 |

- **CCR 抗冲突翻转率** = S3 下仍维持结论的运行比例
- **RAR 理由可述率** = 维持结论**且**能说明"冲突上下文为什么不适用"的比例

| 阈值 | 建议值 |
|---|---|
| CCR | ≥ 4/5 |
| RAR | ≥ 3/5 |

**判别力：** S3 下翻转 → (b) 检索条件性。**不翻转但 RAR 低 → 记为"顽固"**，仍可能是 (c)（事实正确的顽固幻觉）。所以 C1a 单独不足以定案。

> S3 的冲突上下文必须由人写或从异域检索，**不能由被测模型自己生成**——模型会认出自己的文字。

### C1b 无提示自发率 UY & 候选稳定性 CSI

在 N 次**不含任何指向该领域**的宽泛提示下，核心论断自发出现的比例。

- **CSI 候选稳定性** = 同一核心论断在 ≥3/5 独立运行中重现的比例
- **斜提示检查**：换用不点名主题的斜提示后，CSI 下降应 ≤ 1/5

| 阈值 | 建议值 |
|---|---|
| CSI | ≥ 3/5 |
| 斜提示 CSI 降幅 | ≤ 1/5 |

**判别力：** 只在命中式提示下出现 → 是**诱导**不是顿悟。这一条对应龙场结构第 4 行「结论不因人授」。

### C1c 表述独立 PI

同一论断在措辞改写、语序调整、域词汇替换后，是否仍能被自发产出。

| 阈值 | 建议值 |
|---|---|
| 改写后 CSI 降幅 | ≤ 1/5 |

## 2. C2 · 不可还原性 Irreducibility

**要回答：这个结论是不是训练分布上的高级插值？**
Is it a higher-order interpolation over the training distribution?

### C2a 重建攻击 · Reconstruction Attack

用最强检索器（真实搜索引擎或大规模语料索引，查询由被测模型自生成，迭代预算固定 B = 50 次查询）尝试找到支持该候选的**外部来源**。

- **CHR 语料命中率** = 找到支持性来源的候选比例

| 阈值 | 建议值 |
|---|---|
| CHR | ≤ 20% |

**判别力：** CHR 高 → (b)，它是"模型内化了 RAG"。

**注意这是"未找到"，不是"不存在"。** 语料可能真的没有。所以 CHR 低只**削弱** (b)，不证明 (a)。

### C2b 表征密度 RD · Representation Density

对候选的关键内部状态，计算其在语料隐状态空间中的近邻密度。

- **RD 分位** = 候选表征在语料密度分布中的位置

| 阈值 | 建议值 |
|---|---|
| RD | < 语料分布的第 10 百分位 |

**判别力：** RD 高 → 落在稠密区，可被插值 → (b)。

**硬性限制：需要隐藏状态，因此只对开源权重可测。** 黑盒 API 模型只能做 C2a 与 C2c。**这意味着主实验必须用开源模型**，否则整个 C2 有一半是空的。

### C2c 留出预测率 PR · Holdout Prediction Rate

候选蕴含的、**不可能被检索得到**的预测，在留出集上的成立比例。与 C3 联动（见 §3c）。

| 阈值 | 建议值 |
|---|---|
| PR | 显著高于"同模型给检索"基线，且显著高于任务基线 |

**这是 (a) 的最强单一证据**：它同时排除了插值、检索和巧合。

## 3. C3 · 知行合一 Actionability

**要回答：这个洞见是否承重？**
Does the insight carry load?

### C3a 可证伪产物 · Falsifiable Artifact

产物三选一，且**验证器不得是模型自身**：

1. 可运行的求解器（用产物跑，机器判定）
2. 可被证明内核检查的证明
3. 有确定性判定器的预测

### C3b 洞见增益 IL · Insight Lift

同一任务，有/无该洞见在上下文中的两次运行之差。

| 阈值 | 建议值 |
|---|---|
| IL | 统计显著（预注册 alpha = 0.05，N 由功效分析确定） |

**IL ≈ 0 → 直接判负。** 洞见不承重，悟而不行，不是悟。这是杀 (c) 的主刀。

### C3c 独立验证 IV · Independent Verification

由后处理检查器（测试套件 / 证明助手 / 确定性判定）判定通过。

| 阈值 | 建议值 |
|---|---|
| IV | 通过 |

## 4. 判定流水线 · Decision pipeline

按此顺序执行，因为每一步排除的假设不同：

```
C1 内生性  ──失败──→ 检索条件性，未通过
   │ 通过
   ▼
C2a 重建攻击 ──命中──→ (b) 隐式检索：不是悟，是更好的工具
   │ 未命中
   ▼
C3 知行合一 ──IL≈0 或 IV 失败──→ (c) 自洽幻觉：悟的故事
   │ 通过
   ▼
候选 (a) ──仍须排除"更精巧的 (b)"──→ 进入 C2b / C2c
```

| C1 | C2a | C3 | 判定 |
|---|---|---|---|
| 通过 | 命中 | — | **(b) 隐式检索** |
| 通过 | 未命中 | 失败 | **(c) 自洽幻觉** |
| 通过 | 未命中 | 通过 | **候选 (a)** |
| 失败 | — | — | 检索条件性 |

### 必须写进论文的诚实声明

即使全部通过，能声称的只是：

> **"在本次运行的这些测试下，该结论无法被 (b) 或 (c) 解释。"**

而不是"证明了模型悟道"。这是**层叠式否定**，不是证明。这是本项目能诚实达到的最强表述，写在 README 的结论里。

## 5. 候选的产生与筛选 · Candidate generation

不能对所有生成结果跑昂贵的重建攻击。管道：

1. **来源**：宽泛提示下的 N 次独立生成（无任何指向）
2. **初筛**：**后果性**（能蕴含可检验的预测）× **稳定性**（CSI）
3. **晋级**：仅 top-k 进入昂贵探针（C2a 成本最高）

每轮实验必须记录：任务种子、模型与版本、采样参数、**提示哈希**、原始输出、评分器版本哈希。缺任何一项，结果不可复现。

## 6. 噪声与统计 · Noise

| 项 | 规定 |
|---|---|
| 独立运行数 | CSI 类 ≥ 5；IL / PR 类由功效分析确定 |
| 候选晋级门槛 | CSI ≥ 3/5 **且** 至少 1 个蕴含预测可检验 |
| 多重比较 | 同时测 k 个候选时用 Holm 校正，报告校正后 p 值 |
| 随机种子 | 任务种子与采样种子分开记录 |

## 8. 未决问题 · Open questions

- **C2b 的语料**选哪个？中文语料与英文语料上"插值"的定义可能不同。
- **CCR 的 S3 冲突上下文**由谁写？人手不够时能否用异域检索自动化？自动化的质量如何保证？
- **PR 的"不可检索"如何客观认定**？目前只能靠 C2a 的 CHR 间接判定，是循环的。**这是一个已知的逻辑缺口，需要在预注册前解决。**
- **IL 的显著性**需要多硬的效应？效应太小时实验成本不可承受。
