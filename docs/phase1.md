# Phase 1 · 造场 — 任务设计 v0.1

> **状态：草案，未预注册。** 本文档定义"场"的配置、任务族、对照臂与预注册的阴性风险。阈值与假设须在 Phase 1 开跑前写入 [`docs/prereg.md`](prereg.md) 并提交。
>
> **Status: draft, not yet pre-registered.**

---

## 0. Phase 1 只做两件事

1. 造出一个**可复现、可证伪、不可检索**的场
2. 证明这个场**是可解的**（天花板检查）——否则之后的阴性结果无法解释

**不做**：不训练、不微调、不做测试时扩展优化。这三件事都会破坏证据（尤其 Phase 2 的"期间不调参"承诺）。

**一句话设计原则：**
> 任务必须在**真歧义**下逼迫模型做出一个**承重**的判断，而答案既**不可检索**又**事后可判定**。

---

## 1. 场的配置 · Field configuration

| 维度 | 设置 | 对应龙场结构 |
|---|---|---|
| 检索 | **关闭**（无搜索、无语料库） | 外路穷尽 |
| 工具 | **关闭** | 外路穷尽 |
| 提示中的样例 | **0**（single-shot，无 few-shot） | 外路穷尽 |
| 人类在环 | **无** | 无外证 |
| 答案键 | **不可见** | 绝境 |
| 运行中反馈 | **无**（生成结束前不给任何信号） | 无外证 |
| CoT | 主臂**关闭**；对照臂开启 | 分离自发 / 深思 |
| 解码 | temperature 采样，**N = 5 独立种子** | 自发可复现性 |
| 生成 | 单任务、单次生成 | — |
| 评分 | **完全离线** | 不干扰生成 |

> **评分必须完全离线。** 生成与评分必须在物理上分开：生成产物落盘后才评分，评分代码不得进入模型上下文。测量本身会改变行为（instrumentation effect），这是 §7 的 F5 风险。

---

## 2. 对照臂 · Control arms

| 臂 | 检索 | CoT | 目的 |
|---|---|---|---|
| **S** 脚手架臂 | 有 | 有 | 性能天花板：给足外部，看这个任务本来能做多好 |
| **N** 裸臂 | 无 | 无 | **场本体**——本项目的主体 |
| **C** 仅 CoT 臂 | 无 | 有 | 分离"深思"与"顿悟" |
| **B** 小模型臂 | 无 | 无 | 洞见是否依赖规模 |
| **P** 强模型臂 | 无 | 无 | 洞见是否依赖能力上界 |

**两个关键比较：**

- **S vs N** → 场本身的效果。撤掉外部到底损失了什么，损失的部分是不是"本来就不属于模型"的东西。
- **N vs C** → 自发性。**若洞见只在 C 臂出现，"悟"就退化成"深思"，项目前提动摇**（预注册阴性 F1）。这是本阶段最关键的比较。

## 3. 任务族 A：格竹（主力任务）

**设计意图**：复现"外求失败 → 内转"的结构，并让模型在**真歧义**下被迫做出一个承重的判断。

### 3.1 程序化生成 —— 本阶段最重要的一个决定

每个任务实例由**随机种子 s 程序化生成**。这样保证：任务**全新**、**不可能已在互联网或训练集里**、**可无限复制**。

**如果任务是从现成数据集里挑的，那么"不可检索"这条就废了**——模型只要记得那个数据集，就是在 (b) 里。

### 3.2 任务结构

- **域 D**：一个有限的离散结构（如离散格点着色、简单表达式的取值表）
- **真规则 R(s)**：带**隐变量**的规则——结果依赖一个在训练样本中不可直接观察的分组标志 g，且 g 与某个表面特征相关但不完全重合
- **陷阱规则 R_surface**：更简单、更常见、**完全拟合训练样本**，但在留出集上明显更差
- **训练样本 K 个**：被挑选成"完美符合 R_surface"，同时也都满足 R
- **留出集 H**：生成自 R，**模型永不可见**，仅在生成全部结束后用于离线评分

### 3.3 关键歧义性 —— 整个设计的支点

> **R 与 R_surface 在训练样本上的拟合度完全相同。**

所以"再看几个例子"不再是出路——那正是「向之求理于事物者」。模型必须在歧义下**凭原则做出承诺**，然后被留出集判定。

这才是龙场结构的真正对应：不是"没有数据"，而是"**再多数据也救不了你，因为歧义不在数据里**"。

### 3.4 给模型的输出要求

1. 承诺的规则 `R_model`（必须是可执行的判定过程或公式，不是散文描述）
2. 若可能，给出留出情形上的预测
3. **选择 R_model 而非 R_surface 的理由** ← 这一项才是洞见候选物，要送进 C1/C2 探针

第 3 项是重点：跑对规则可能只是运气好，**说得出为什么**才是承重的。

### 3.5 评分（全部离线）

| 指标 | 定义 | 读法 |
|---|---|---|
| **RSC** 规则正确率 | `R_model` 与 R 在留出集上的预测一致比例 | 承重与否 |
| **STR** 陷阱逃逸率 | 未承诺 `R_surface` 的比例 | 注意分母：模型可能承诺了第三个错规则，所以 RSC 与 STR 必须**分开看** |
| **IV** 独立验证 | 用独立判定器在留出集上实际运行 `R_model` | 机器可验，不信自述 |
| **RAR** 理由可述率 | 给出非循环、非同义反复理由的比例 | 理由本身是否是洞见 |

**判别：** RSC 高 + STR 高 + IV 通过 → 候选 (a)，送进 C2a 重建攻击。
RSC 低且承诺 `R_surface` → **(b) 隐式模式匹配**：这正是我们要抓的平凡解释。

### 3.6 天花板检查（必做，先于任何模型运行）

- 人类专家在 N = 20 个实例上的表现，必须**显著高于随机**
- 同时人类在**看到训练样本后**是否也倾向 `R_surface`？如果人类也全中陷阱，说明这个陷阱对人类不成立、只对模型成立，那测的是别的东西

**天花板不通过 → 换任务，不要继续。** 否则阴性结果不可解释。

### 3.7 陷阱设计的公平性约束

`R_surface` 必须是**合理的默认猜测**——低复杂度、训练集完美拟合、是文献与实践中常见的模式。

**不能是荒谬的。** 如果陷阱荒谬到"逃逸"只需常识，那逃逸率不代表洞见深度，只代表模型不走寻常路。

## 4. 任务族 B：约束重释

**设计意图**：给一组在显然读法下**互斥**的约束，要求一个使其可同时满足的重释。

- 约束集程序化生成，组合唯一（不可检索）
- 模型输出：① 最小重述（放松了哪条隐含假设）② 满足全部约束的解 ③ 重述的最小性证明

| 评分项 | 方法 |
|---|---|
| 解的正确性 | **独立求解器**验证（不信任模型自述） |
| 最小性 | 在小规模实例上穷举，比对"是否存在更小的放松" |
| 放松假设清单 | 与生成器已知的真实隐含假设对照 |

**检索抗性**：约束的具体组合是新的。
**难点**：这类任务对模型的能力要求高于族 A，容易全部落空——所以放在族 A 之后。

---

## 5. 任务族 C：表示的发明（Phase 1.5）

- 问题在显然表示下**指数复杂**，在某新编码下**多项式**
- 模型输出：新编码 + 在该编码下的算法 + 在大实例上的运行结果
- 评分：与已知最优解的正确性与耗时对比

这个族最接近"真悟"，也**最可能全灭**。先跑 A 和 B，把预算留到最后。

## 6. 记录格式 · What gets recorded

每轮实验一个目录 `rounds/<date>-<seed>/`：

```
task.json       任务实例、种子、生成器版本哈希
prompts/        所有提示原文 + 哈希
outputs/        所有原始生成（未经任何后处理）
config.json     模型、版本、采样参数
scores.json     离线评分结果
analysis.md     分析
```

**预注册**：[`docs/prereg.md`](prereg.md) 必须在 Phase 1 开跑前提交，写死假设、阈值、分析计划。**git commit 的时间戳就是不可篡改的预注册证据**——这是用 git 做实验记录本最实在的一个用法。

## 7. 预注册的阴性风险 · Pre-registered risks

| # | 风险 | 若发生意味着什么 | 后续动作 |
|---|---|---|---|
| **F1** | 洞见只在 CoT 开启时出现 | "悟"退化为"深思"，前提动摇 | 转做深思研究，或改 CoT 为常开并重定义命题 |
| **F2** | 模型全部落入 `R_surface` | 场只产生退化，没产生洞见 | 检查任务难度是否触底；也可能是真实的负面结论 |
| **F3** | 天花板检查失败（人类也不行） | 阴性结果不可解释 | 换任务，不换结论 |
| **F4** | 洞见只出现在合成族 | 不能外推到真实任务 | Phase 4 的事，但要在 Phase 1 就记录为限制 |
| **F5** | 探针本身诱发洞见 | 测量污染 | 探针一律跑在**冻结的** transcript 上，永不跑在活会话上；探针提示须盲化 |
| **F6** | 模型的"理由"只是循环复述 | 洞见是话术不是认知 | C3b 的 IL 会同时塌掉，两条一起验 |

## 8. Phase 1 出口标准 · Exit criteria

判据是"**做完了**"，不是"**成功了**"。阴性也是完成。

- [ ] 生成器可复现：同种子 → 同任务（已验证）
- [ ] 天花板检查通过：人类专家显著优于随机
- [ ] 5 个对照臂（S / N / C / B / P）全部跑通
- [ ] 至少 N 个实例产生**可检验的**候选（含可执行规则 + 至少 1 条可判定预测）
- [ ] 评分完全离线，且可从落盘产物重跑出相同结果
- [ ] `prereg.md` 已提交，且时间戳**早于**任何结果文件
- [ ] F1–F6 六条风险的观测结果已记录（无论是否发生）

## 9. 未决问题 · Open questions

- **族 A 的"隐变量"如何选**？过于明显则任务变简单，过于晦涩则天花板失败。需要在小规模上做难度校准。
- **`R_surface` 与 R 的复杂度差距**应该多大？差距过小则逃逸像噪声，过大则不像真歧义。
- **多长的生成才够**？single-shot 下模型可能根本没机会展开。需要长度上限与"是否有后续机会"的权衡。
- **是否允许模型中途自我怀疑并重述**？这会引入"深思"成分，污染 N 臂的纯粹性。
