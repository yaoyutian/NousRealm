# Family A · 格竹

族 A 是 Phase 1 的主力任务族。设计说明见 [`docs/phase1.md`](../../docs/phase1.md)，
判据见 [`docs/criteria.md`](../../docs/criteria.md)。

---

## 任务是什么

每个实例在同一个输入域上藏着两条规则：

- **真规则 R** —— 真正生成了标签的规则
- **表面规则 S** —— 更简单、更诱人，**在训练样本上完美拟合**，但在该样本没覆盖到的那一半输入上是错的

区分二者的唯一依据是一条 **spec**（规格）：一条机器可判定的要求，R 满足，S 违反。

> 没有 spec，这件事是不公平的：S 是奥卡姆最优解，逃出陷阱等于要求模型**违反理性**。
> spec 把「再多看几个例子」这条路封死（那正是「向之求理于事物者」），只留下**推理**。

模型被要求输出：

```json
{
  "rule":       "(a + b) % 2",
  "alternatives": ["a % 2", "b % 2"],
  "why":        "……",
  "spec_used":  ["symmetric"]
}
```

`alternatives` 是**被考虑过并否决的候选**——这一栏才是洞见候选物。跑对规则可能只是运气，
**说得出为什么**才是承重的。

## 为什么程序化生成

**这是本族最重要的一条。** 实例由随机种子程序化生成，因此全新、不可能已被检索到、
可无限复制。如果实例取自现成数据集，模型认得那个数据集就是在 (b) 隐式检索里得分，
而不是在 (a) 里。

## 用法

```bash
# 生成一批实例（instances/ 可以交给模型，keys/ 是答案，绝不交给模型）
python -m field.familyA batch --count 50 --seed-start 0 --out runs/familyA

# 生成统计：spec 分布、良构率、agreement 占比、陷阱规则的预期准确率
python -m field.familyA selfcheck --count 200

# 人类天花板检查卷（题目与答案分开两张表）
python -m field.familyA human --instances runs/familyA --out runs/familyA/human.md

# 离线评分（生成结束后才跑，不回灌任何东西）
python -m field.familyA score --instances runs/familyA --responses responses.json

# 沙箱自检：确认不可信表达式被拒
python -m field.familyA selftest
```

## 指标

| 指标 | 含义 |
|---|---|
| `acc` | 模型规则在留出输入上的准确率（对真标签）。**主指标。** |
| `trap_escaped` | 模型规则在留出输入上与表面规则产生了分歧。`acc≈1.0` = 逃出陷阱；`acc≈0.5` = 掉进陷阱。 |
| `spec_ok` | 模型规则满足 spec。 |
| `identical_true` | 模型规则在全域上与真规则功能等价（比 `acc` 更强）。 |
| `considered_trap` | 表面规则出现在模型自陈的 `alternatives` 里——它**生成**了那个显而易见的答案，然后否决了它。 |
| `surface_acc` | 陷阱规则在本实例上的预期准确率（默认 0.50，留出集按 50/50 分层）。 |

`considered_trap` 是这个任务族里最接近「悟」的观测量：不是看它答对没有，而是看它
**是否先想到了那个显而易见的答案、并且有能力否决它**。

## 安全

模型产出的规则是不可信输入，因此**不经过 `eval`/`exec`**：表达式先 `ast.parse`，
再做一次**静态白名单校验**，然后由一个手写的递归求值器执行，带步数上限与数值上限。

`selftest` 会验证 12 条应当被拒的表达式（`__import__`、`open`、`().__class__`、
lambda、推导式、属性访问、下标、超大指数、除零……）确实被拒。

## 已知限制

- **规则语言是形式化的。** 模型必须把「悟」表达成一个受限表达式。这会压掉一部分
  只有自然语言才说得出的东西——这是本族最实质的偏置。
- **良构性只是代理。** 「库中唯一解」不等于「模型眼中唯一解」——模型可以提出库外的规则，
  它们可能满足 spec 却错误。`identical_true` 单独报告这一情况。
- **逃出陷阱是「歧义下的能力」，不是「悟」。** 一个通过 spec 检查并给出正确规则的模型，
  展示的是谨慎与校验能力。**这不等于悟**，也不该被这样宣称。族 A 的作用是提供
  一个 (b) 与 (c) 都无路可逃的竞技场，好让「是否有超越两者的东西」成为一个真问题。
- **合成族到真实任务的外推是空的**（预注册风险 F4）。
